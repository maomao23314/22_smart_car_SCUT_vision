## v1.1

**界面**
- 右侧参数区改为**三个并列的可折叠区块**：基础光照 / 高级参数 / 仿真联动
  （此前「仿真联动」被嵌在「高级参数」里面，层级关系不对）
- 新增**对比度**参数
- 每个参数**都能直接输入精确值**，并配单独的重置按钮（↺）
- 光斑**衰减曲线**可调：控制中心亮区占比与边缘陡峭程度
- 窗口标题与顶栏加入车队标识

**仿真联动**
- 新增：处理结果可直接写回仿真环境正在显示的图片，
  环境**自动重读并重跑算法**（对应仿真环境侧 `env\hot_reload.c`）
- 支持「停止操作后自动上传」，等待时间可调
- 目标路径可配置，默认自动猜测仿真环境图集目录

**交互**
- 鼠标拖动平移，双击复位
- 滚轮缩放、`适应` 按钮自动选倍率
- 快捷键：`←/→` 翻页、`Ctrl+O` 打开、`Ctrl+S` 保存、`+/-` 缩放

**修复**
- 同目录翻页时，「下一张」总是跳回第一张
  （路径精确字符串匹配失败导致下标为 -1）
- 自增命名：`1` 曾会变成 `11`、`12`
- 数字结尾的文件名会被其它位数的文件干扰（如 `2` 被 `11.bmp` 顶成 `12`）
- 线性反光角度语义反直觉（0° 原本是竖直光带）

**打包**
- 改用官方 PyPI 的 numpy（OpenBLAS），避免被 Anaconda 的 Intel MKL
  拖进 600+ MB 的数学内核。未压缩产物从 680 MB 降到 23 MB（单文件）/ 58 MB（文件夹）

## v1.0

首个可用版本。

**功能**
- 读取并显示图像（BMP / PNG / JPG），支持同目录翻页
- 曝光调整（整体亮度增益，模拟曝光时间）
- 点光源：点状扩散光斑，模拟阳光照射
- 线性反光：条状高光，模拟反光
- 保存：自由命名 + 自增 + 覆盖询问，支持 BMP / PNG / JPG
- 缩放（整数倍档位）、参数导出/导入为 JSON

**技术选型**
- Python + Tkinter + numpy + Pillow
- 零第三方 GUI 框架，无安装成本
- `render()` 设计为纯函数，便于将来替换实现
- 界面由 `PARAM_SPECS` 一张表驱动，加参数只需加一行
