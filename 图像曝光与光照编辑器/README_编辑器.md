# 图像曝光与光照编辑器

给赛道图叠加**曝光、光斑、反光**，快速造出各种光照条件的测试图，
用来验证视觉算法在逆光、炫光、水面反光等场景下会不会翻车。

配套 [22 华工智能车竞速组考核视觉仿真](../22华工智能车竞速组考核视觉仿真/README_仿真环境.md) 使用，
支持**一键把结果写回仿真环境并自动重跑算法**。

> 返回 [仓库总览](../README.md)

---

## 效果

一张原始赛道图，可以变成：

| 效果 | 模拟场景 |
|---|---|
| **曝光** | 曝光时间变化（整体变亮/变暗） |
| **对比度** | 硬光 / 灰雾天 |
| **点光斑** | 阳光直射、逆光炫光 |
| **线性反光** | 水面反光、玻璃反射 |
| **衰减曲线** | 从柔和弥散到强聚光，控制亮区占比 |

## 快速上手

### 方式一：直接用 exe（推荐，不用装任何东西）

仓库里已经放好了**打包好的成品**：

| 交付形态 | 怎么做 | 体积 | 启动 |
|---|---|---|---|
| **`单文件版\`** | 双击 `图像曝光与光照编辑器.exe` | 约 23 MB | 约 6 秒 |
| **`文件夹版.zip`** | **解压后**双击里面的 exe | 约 24 MB（解压后 58 MB） | **约 1 秒** |

两者**功能完全一样**：

- **单文件版** —— 就一个 exe，适合拷到 U 盘、发给别人
- **文件夹版** —— 启动快得多，适合放在电脑上天天用

> **为什么不自己编译？** 没必要。这两个已经是成品，拿到就能跑。
> 只有你要改编辑器代码时才需要看方式二。
>
> **文件夹版为什么要压成 zip？** 解压后里面有 2001 个依赖文件
> （dll 和 tcl 脚本）。直接放进仓库会让文件数暴涨、克隆变慢，
> 压成一个包只占 1 个文件对象，不影响使用。

### 方式二：跑源码（要改代码时用）

需要 Python 3.8+：

```
pip install numpy pillow
python image_editor.py
```

无其他依赖，全部是可自由使用的开源库。

### 自己重新打包

改完代码想重新生成 exe：

```
pyinstaller build_onefile.spec --distpath dist_onefile    # 单文件
pyinstaller build_exe.spec     --distpath dist            # 文件夹
```

> **体积陷阱**：不要在 Anaconda 环境里打包。Anaconda 的 numpy 链接 Intel MKL，
> 光数学内核就 600+ MB。用官方 PyPI 的 numpy 只有约 31 MB。

## 界面说明

左侧是图像，右侧是三个**并列**的可折叠区块，底部是保存条。

```
▼ 基础光照      曝光 / 对比度 / 点光源强度 / 线性反光强度
▶ 高级参数      光斑位置与形状 / 反光方向与形状 / 导出·导入参数
▶ 仿真联动      目标文件夹 / 目标文件名 / 自动上传
```

> 三个区块是**平级**关系，展开顺序不会打乱它们的上下次序。
> 「仿真联动」不会跑进「高级参数」里面。

### 基础光照

| 参数 | 作用 |
|---|---|
| 曝光 | 整体亮度增益，模拟曝光时间 |
| 对比度 | 围绕中灰拉伸，>1 更硬，<1 更灰 |
| 点光源强度 | 阳光光斑强度 |
| 线性反光强度 | 条状高光强度 |

### 高级参数

**点光斑**：水平/垂直位置、扩散半径、衰减曲线
**线性光斑**：角度（0° 水平，90° 垂直）、偏移、条宽、衰减曲线
**衰减曲线**：往右拖 → 中心亮区更大、边缘更陡（强聚光）；往左拖 → 边缘柔和（弥散光）

还能**导出/导入参数**为 JSON，方便固化一套光照条件复用。

## 图像调整技巧

- **每个参数都能直接输入精确值**，不用拖滑块
- **每个参数有单独的重置按钮**（↺），标题栏还有「全部重置」
- **支持鼠标拖动平移**，双击画布复位
- **滚轮缩放**，或点「适应」按钮自动选合适倍率
- 快捷键：`←` `→` 翻页、`Ctrl+O` 打开、`Ctrl+S` 保存、`+` `-` 缩放

## 仿真联动

### 怎么用

1. 打开仿真环境，翻到你想调的那张图（比如 `pic\1\1.bmp`）
2. 在本编辑器的「仿真联动」区：
   - **目标文件夹** → 指向 `pic\1`（一般能自动猜出来）
   - **目标文件名** → 填 `1`
   - 勾上 **停止操作后自动上传**，等待时间按喜好设（默认 800 毫秒）
3. 拖滑块。**停手约 800 毫秒后，仿真环境会自动重新读图并重跑算法。**

不想自动的话，取消勾选，点 **立即上传到仿真环境** 也一样。

### 原理

编辑器把结果**写到正在显示的那张图本身**上，仿真环境监测该文件时间戳变化后重读重跑。
所以翻到哪张就盯哪张，不需要额外目录，两端也不直接通信。

对应仿真环境侧实现：`env\hot_reload.c`

## 保存

底部保存条：**文件夹 / 文件名 / 自增 / 覆盖 / 格式**（BMP / PNG / JPG）。

**自增规则**：

| 输入 | 结果 |
|---|---|
| `1` | `1` → `2` → `3`（数字结尾则递增这个数字） |
| `out` | `out1` → `out2` → `out3`（非数字结尾则追加序号） |
| `img007` | `img008`（保留补零位数） |

序号是**扫描磁盘**算出来的，不是内存计数器，所以程序重启后不会重名。

未勾选「覆盖」时，遇到同名文件会弹窗询问。
