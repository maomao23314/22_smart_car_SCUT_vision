## v1.1

本次为联动与工具链改进版本，可与配套的图像编辑器（`img_editor`）协同工作。

**新特性**
- **热重载**：环境会监测「当前正在显示的那张图片」是否被外部程序改写，
  一变就自动重新读图并重跑算法，不用再手动按 `+` 翻页
  - 配套编辑器保存/上传后即可实时看到算法结果
  - 运行时按 `H` 可随时开关，状态栏显示 `[热重载 开 已刷新 N 次]`
  - 相关配置见 `config.h` 的 `SCUT_HOT_RELOAD` / `SCUT_HOT_RELOAD_COOLDOWN_MS`
  - 实现见 `env\hot_reload.c`（接口 `env\hot_reload.h`）
- 未开新线程：EasyX 的 GDI 对象非线程安全，改用轮询文件属性的方式，
  开销可忽略且不存在数据竞争
- 三重保护避免「算法慢 + 频繁刷新」把程序拖垮：
  写完成判定（签名连续 2 次不变才重载）、冷却时间（默认 300ms）、轮询节流（80ms）

**工具链**
- 新增 `tools\find_msbuild.bat`：通过官方 `vswhere` 自动定位 MSBuild，
  **不再限定 Visual Studio 版本**（2017 / 2019 / 2022 / 后续版本，
  Community / Professional / Enterprise / Build Tools，任意安装盘符均可）
  - 存在多个 VS 安装时，优先选择**确实装了 EasyX** 的那个，
    避免误选 Build Tools 后报 `cannot open include file: easyx.h`
- `一键配置.bat` 重写：适配多版本 VS，同时报告编译器版本与 EasyX 状态
- `build_dev.bat` 改为**自动发现** `env\*.c` / `env\*.cpp` / `*.cpp`，
  不再硬编码源文件列表

**问题修复**
- 修复 Dev-C++ 工程缺少 `env\hot_reload.c` 单元导致链接失败
  （`undefined reference to SCUT_HotReloadInit` 等 6 个符号）
- 修复 `build_dev.bat` 硬编码源文件列表、新增 `env\*.c` 时被静默漏编
- 修复首次拉取代码后编译时，VS 工程项在构建中途才被脚本重写、
  导致当次构建看不到新文件而链接失败的问题
- 修复热重载提示文字与「处理时间」文字重叠

## v1.0

本次为重构版本，在 21 届环境的基础上重写了接口与工程结构。

**新接口**
- 接口统一改为 `SCUT_XXX` 风格，命名与注释格式参考逐飞 CH32V307 开源库的屏幕驱动，便于后续移植到车载程序
- 绘图：`SCUT_DrawPoint` / `SCUT_DrawLine` / `SCUT_DrawRect`
- 日志：`SCUT_Log` / `SCUT_LogAt` / `SCUT_LogClear`，移除了旧的 `PRINT` 接口
- 颜色：`SCUT_COLOR_xxx`，定义在 `env\scut_common_typedef.h`

**新特性**
- 窗口随日志自动加高，日志写不下时不会再被挤掉
- 左键取像素值移到窗口右上角，改用浅蓝色，不再与日志文字重叠
- `code\` 目录自动收集，新建 `.c` / `.h` 无需修改工程设置
- 图片改用相对路径读取，exe 放在哪个子目录都能找到 `pic\`
- 新增 `一键配置.bat`，一次完成文件扫描、编译器与 EasyX 检查、首次编译

**工程**
- 支持真正的 C / C++ 混合编译：`code\*.c` 走 C 编译器，`.cpp` 走 C++ 编译器
- 用户代码不依赖图形库，可直接移植到单片机
- 新增 `tools\verify_mixed.ps1`，用于检查混合编译是否正确
- VS 工程与 Dev-C++ 工程均已配好，打开即可编译运行
- `config.h` 重新整理，用户配置在前、环境参数在后，每项带说明

**问题修复**
- 修复中文显示乱码
- 修复图片读取失败、一直显示渐变图
- 修复切换图片后画面拉伸
- 修复控制台诊断信息不可见
- 修复 `camera.c` 被当作 C++ 编译
- 修复按 `R` 做复杂度测试时日志刷屏
- 修复 Dev-C++ 打开工程后项目列表空白、找不到头文件、项目名乱码
- 修复 VS 通配符警告、按 F5 时新建文件不被编译
- 修复 VS 每次生成后提示「文件已更改，是否重新加载」

**文档**
- 新增 `readme.md`（新手上手指南）与本更新日志

## v0.8

21 届版本，环境框架的初始版本。

- 原图像 / 处理后的图像并排显示
- `+` / `-` 切换图片，跨图集自动翻页
- `Ctrl` + `+` / `-` 实时缩放
- `R` 键做 1000 次重复的复杂度测试，显示平均耗时
- 鼠标左键取像素灰度值
- 图片读取失败时显示渐变图兜底
- `UNUSE_IMAGE(n)` 屏蔽指定图片
