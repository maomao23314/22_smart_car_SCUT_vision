# 流眄 / Liumian

> 华工智能车队 · 视觉算法开发工具包

**流眄**（liú miǎn）取自《洛神赋》「容与乎阳林，流眄乎洛川」，本意是纵目四望。
摄像头扫过赛道，不外如是。

这套东西干两件事：

- 在电脑上模拟 MT9V03X 灰度摄像头和 IPS 屏，不用上车就能调视觉算法
- 造各种光照条件的测试图，看看算法在逆光、炫光、水面反光下会不会翻车

两者能联动：编辑器调好光照存回原图，仿真环境自动重跑算法，不用手动翻页。

## 上手

### 1. 配置（只做一次）

进 `Liumian-SimuEnv\`，双击 `一键配置.bat`。
它会找编译器（Dev-C++ 或任意版本 Visual Studio）、检查 EasyX，然后问你要不要立刻编译。

### 2. 写代码

只改 `code\` 目录，重点是这两个函数：

```c
void image_init(void)      // 开机初始化，不需要就留空
int  image_process(void)   // 每帧的图像处理主函数，环境自动调用并计时
```

`code\camera.c` 里那份示例（大津法 + 扫线）只是演示接口怎么用。
它没处理十字、环岛、坡道，也没有补线和丢线保护，噪点一多中线就乱跳。
当成 Hello World 看，算法得自己写。

在 `code\` 下新建 `.c` / `.h` 不用改任何工程文件，会自动收集，也支持子文件夹。

一个例外：Dev-C++ 没有「编译前执行命令」，按 F11 不会重新扫描 `code\`。
所以新增、删除、改名文件之后，先双击一次 `tools\rebuild.bat` 再按 F11。
VS 和命令行脚本都会自动重扫，不用管。症状是新建了文件却报一堆
`undefined reference to ...`，看着像代码写错了。

### 3. 编译运行

| 方式 | 操作 |
| --- | --- |
| Dev-C++ | 打开 `视觉仿真环境.dev`，按 F11 |
| Visual Studio | 打开 `VS\visual_simu.sln`，按 F5 |
| 命令行 | 双击 `tools\build_dev.bat` 或 `tools\build_vs.bat` |

### 4. 造测试图

进 `图像曝光与光照编辑器\`，仓库里已经打包好了 exe，不用装任何东西。

`单文件版\图像曝光与光照编辑器.exe` 直接双击就能用，约 23 MB，启动约 6 秒，
适合拷给别人。`文件夹版.zip` 解压后双击里面的 exe，启动约 1 秒，适合天天用。
两者功能一样。

要改编辑器代码才需要装 Python：

```
pip install numpy pillow
python image_editor.py
```

## 说明

算法代码（`code\*.c`）不依赖图形库，对外只依赖 `code\lm_port.h` 一份头文件。
整个 `code\` 目录原样拷到 CH32V307 车载程序就能编译，一行都不用改
（见[移植说明](Liumian-SimuEnv/README_仿真环境.md)）。
要显示的图像、尺寸、ROI、摄像头分辨率都在 `config.h` 里配，算法里不写死。
`env\` 是环境本体，一般不用动。

遇到问题先看各自的 README，都有常见问题一节。
