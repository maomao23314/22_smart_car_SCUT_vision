## 快速上手

### 1. 配置环境（只做一次）

进 `22华工智能车竞速组考核视觉仿真\`，双击 **`一键配置.bat`**。

它会自动找编译器（Dev-C++ / 任意版本 Visual Studio）、检查 EasyX，并问你要不要立刻编译。

### 2. 写你的代码

只改 `code\` 目录，主要就一个文件：

```c
void image_init(void)      // 开机初始化，不需要就留空
int  image_process(void)   // 每帧的图像处理主函数，环境自动调用并计时
```

在 `code\` 下新建 `.c` / `.h` **不需要改任何工程文件**，会自动收集进去。

### 3. 编译运行

| 方式 | 操作 |
|---|---|
| Dev-C++ | 打开 `视觉仿真环境.dev`，按 `F11` |
| Visual Studio | 打开 `VS\visual_simu.sln`，按 `F5` |
| 命令行 | 双击 `tools\build_dev.bat` 或 `tools\build_vs.bat` |

### 4. 想造图的时候

进 `图像曝光与光照编辑器\`，装好 Python 后：

```
pip install numpy pillow
python image_editor.py
```

或者直接用已打包好的 exe。
